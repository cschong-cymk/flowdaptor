Flowdaptor Releases DealKaki, an AI-Powered Deal-Matching Agent

Today we’re launching DealKaki: an intelligent deal-matching agent that sits between deal supply and demand, helping sellers and buyers find each other for block trades and private transactions.

In Japanese, torihiki (取引) means trade or transaction. DealKaki is built to be your torihiki matching genius — reading intent, ranking fit, and surfacing the right deal to the right counterparty.

What DealKaki does

Private transactions move through networks, spreadsheets, and introductions. DealKaki replaces that noise with a single AI agent that:

  • Profiles buyers and sellers from directories, websites, and provided information
  • Infers preferences like deal size, asset class, sector focus, sustainability criteria, and track record
  • Ranks matches by probability
  • Generates tailored teasers for different buyer profiles
  • Learns from feedback and outcomes over time

The same user can interact with DealKaki as a seller or a buyer — the agent adapts to either side of the table.

Core features

1. AI Matching Engine

DealKaki fuzzy-matches public and provided data to infer what each party is actually looking for. The engine then produces ranked match probabilities, so deal teams spend time on the highest-quality introductions instead of cold outreach.

2. Curated Teaser Generation

Every deal has a “soul.” DealKaki identifies what makes a transaction distinctive and generates tailored teasers for different buyer types. The same underlying deal can be presented differently to a credit-focused family office, a sustainability-driven fund, or a sector specialist.

3. Buyer Sourcing

Buyer discovery starts with Singapore family office directories and expands to deal-specific groups — property investors for hotel deals, wine enthusiasts for tokenised wineries, and so on. The agent enriches leads automatically so the pipeline stays fresh.

4. Admin Dashboard

The new dashboard gives deal operators a ranked list of buy/sell matches, surfaced by match probability. Review matches, provide feedback, and optionally auto-send curated teasers — all from one place.

The dashboard also flags what needs attention: expired deals, unowned deals, missing sizes, and drafts still waiting to go live.

5. WhatsApp Channel

DealKaki runs on a dedicated WhatsApp number. Sellers and buyers can submit deals, ask questions, and receive matches through a natural conversation — no new app to install.

6. Learning System

Match quality improves with every interaction. Feedback, buy/sell patterns, and outcomes feed back into the engine, so rankings get sharper over time.

Built for block trades and private deals

DealKaki is designed for transactions that don’t fit public markets: block trades, pre-IPO placements, asset sales, capital raises, and similar private deals where timing, fit, and discretion matter.

By combining domain-aware matching, tailored storytelling, and a conversational interface, DealKaki helps deal originators find the right counterparty faster — and helps buyers discover opportunities that actually match their mandate.
